# YOLOv5 Cat Detection using COCO Dataset

Bu proje, COCO veri setinden yalnızca **kedi sınıfını** ayıklayıp YOLOv5 modeliyle eğitilmiş bir kedi algılama sistemini içerir. Eğitim süreci Google Colab üzerinde gerçekleştirilmiştir ve bu repo hem Jupyter Notebook'u hem de veri setini içerir.

---

## Kullanılan Teknolojiler

- Python
- PyTorch
- YOLOv5
- Google Colab
- COCO Dataset

---

## Veri Seti Bilgisi
Proje, COCO 2017 veri setinden yalnızca "kedi" sınıfını içerecek şekilde özel olarak ayıklanmış bir veri seti ile çalışır. Ayıklama işlemi sırasında kullanılan etiketler ve görüntüler, eğitim ve test verileri için ayrılmıştır.
